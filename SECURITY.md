# Security and verification

Zephyr source code is available for inspection. Build instructions and third-party notices are included in this repository.

SHA256SUMS.txt records the SHA-256 hashes of the locally built installer, executable and component binaries. Hashes identify exact files; they do not prove that those files are safe.

No independent security audit has been completed. The bundled precompiled LeagueToolkit patcher has not been audited by this project. Reproducible builds and correspondence between the published source and installer have not yet been independently verified.

This project does not claim to be 100% safe or independently audited.
