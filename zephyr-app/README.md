# Zephyr app 1.0.0

Current executable launcher, menu extension, bilingual interface and in-game menu source. See BUILDING.md for required local inputs.

The distribution folder contains Zephyr.exe, README.txt, runtime, resources and licenses. Development and update scripts are excluded from the application package.

Version 1.0.0 adds GitHub stable-release notifications in English and Portuguese. Settings includes a manual check. Updates are downloaded and installed manually.
First-launch game path detection respects existing paths. Startup shows the Zephyr logo and fades into the interface once ready.
